# Security Policy

Author: anilbudthapa

This repository is documentation-only, but security hygiene still matters.

## Reporting

If you find sensitive data, exposed credentials, or unsafe guidance in this repository, open a private security advisory or contact the maintainer before creating a public issue.

## Secret Handling

- Do not commit API keys, tokens, passwords, private keys, customer data, or internal infrastructure details.
- Use placeholder examples only.
- If a real secret is committed, rotate it immediately and remove it from history before public distribution.
