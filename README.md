## Short Description

`SSE.md` is a production-grade Claude Code operating doctrine for builders who want an AI coding assistant to behave more like a senior software engineer. It gives Claude Code clear rules for understanding a repository, planning work, writing maintainable code, testing honestly, reviewing security, documenting changes, and shipping with confidence.

This is an unofficial Claude Code inspired documentation repository. The animated logo is custom artwork, not an official Anthropic or Claude logo.

## Download

Clone the repo:

```bash
git clone https://github.com/anilbudthapa1/sse-operating-doctrine.git
cd sse-operating-doctrine
```

Download the release package:

```bash
curl -L https://github.com/anilbudthapa1/sse-operating-doctrine/releases/latest/download/sse-operating-doctrine-v1.1.0.zip -o sse-operating-doctrine.zip
```

Download only the Claude Code files into your current project:

```bash
curl -L https://raw.githubusercontent.com/anilbudthapa1/sse-operating-doctrine/main/SSE.md -o SSE.md
curl -L https://raw.githubusercontent.com/anilbudthapa1/sse-operating-doctrine/main/CLAUDE.md -o CLAUDE.sse.md
```

Download as GitHub ZIP:

```text
https://github.com/anilbudthapa1/sse-operating-doctrine/archive/refs/heads/main.zip
```

## Use With Claude Code

1. Open your project in Claude Code.
2. Add `SSE.md` to the project root.
3. Copy `CLAUDE.md` into your project, or merge its content into your existing `CLAUDE.md`.
4. Start Claude Code with this instruction:

```text
Read CLAUDE.md and SSE.md. Follow this Senior Software Engineer operating doctrine for planning, coding, testing, security review, documentation, DevOps, and final reporting in this repository.
```

Core workflow:

```text
understand -> plan -> implement -> verify -> report
```
