## Short Description

`SSE.md` is a production-grade Claude Code operating doctrine for builders who want an AI coding assistant to behave more like a senior software engineer. It covers product thinking, architecture, clean code, security, testing, documentation, DevOps, release checks, and agent roles.

This is an unofficial Claude Code inspired documentation repository. The animated logo is custom artwork, not an official Anthropic or Claude logo.

## Download

Clone the repository:

```bash
git clone https://github.com/anilbudthapa1/sse-operating-doctrine.git
cd sse-operating-doctrine
```

Download as ZIP:

```text
https://github.com/anilbudthapa1/sse-operating-doctrine/archive/refs/heads/main.zip
```

Download inside Claude Code or any terminal:

```bash
curl -L https://raw.githubusercontent.com/anilbudthapa1/sse-operating-doctrine/main/SSE.md -o SSE.md
curl -L https://raw.githubusercontent.com/anilbudthapa1/sse-operating-doctrine/main/CLAUDE.md -o CLAUDE.sse.md
```

## How To Use

1. Read [`SSE.md`](SSE.md) as the master doctrine.
2. In Claude Code, open your project folder.
3. Add `SSE.md` and either copy [`CLAUDE.md`](CLAUDE.md) into your project or merge its instructions into your existing `CLAUDE.md`.
4. Ask Claude Code:

```text
Read CLAUDE.md and SSE.md. Follow this Senior Software Engineer operating doctrine for planning, coding, testing, security review, and final reporting in this repository.
```

Use the core workflow before shipping:

```text
understand -> plan -> implement -> verify -> report
```
