# Senior Software Engineer (SSE) Operating Doctrine

Author: anilbudthapa

This repository contains a production-grade operating doctrine for using Claude Code as a senior software engineering system. The doctrine is organized as a practical ruleset for planning, building, testing, reviewing, securing, documenting, and shipping software products with discipline.

## Repository Contents

- `SSE.md` - the master operating doctrine.
- `CLAUDE.md` - a short Claude Code entry point that points to the doctrine.
- `CHANGELOG.md` - release history for the repository.
- `CONTRIBUTING.md` - contribution expectations.
- `SECURITY.md` - security reporting and secret-handling guidance.
- `LICENSE` - current copyright and usage terms.

## Purpose

The doctrine is designed for builders who want an AI coding assistant to operate with stronger engineering habits:

- product and architecture awareness
- security-first implementation
- careful repository and worktree handling
- evidence-based testing and reporting
- release and documentation discipline
- agent role definitions for complex work

## How To Use

Read `SSE.md` as the source document. If you want Claude Code to apply this doctrine inside another project, copy the relevant rules into that project's `CLAUDE.md` or reference this repository from your project documentation.
