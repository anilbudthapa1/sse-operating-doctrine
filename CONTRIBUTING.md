# Contributing

Author: anilbudthapa

This repository is currently maintained as a documentation-first project. Contributions should keep the doctrine practical, clear, and internally consistent.

## Guidelines

- Keep changes focused on one topic.
- Preserve the existing rule structure unless a broader reorganization is clearly justified.
- Avoid adding speculative rules that cannot be followed or verified.
- Do not include secrets, private project data, customer data, or proprietary implementation details.
- Update `README.md` or `CHANGELOG.md` when a change affects repository usage or release history.

## Suggested Pull Request Checklist

- The change is scoped and easy to review.
- Markdown headings and lists render correctly.
- No secrets or private data are included.
- The rationale for the change is clear.
